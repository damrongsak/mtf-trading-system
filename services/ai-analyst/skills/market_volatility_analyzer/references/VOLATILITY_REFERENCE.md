# Volatility Interpretation Reference

## 📊 Volatility Regimes

| Ratio (HV20 / HV60) | Regime Name | Description |
| :--- | :--- | :--- |
| < 0.8 | **Compression** | Market is abnormally quiet. High probability of an imminent breakout. |
| 0.8 - 1.2 | **Normal** | Equilibrium. Trend-following strategies work best here. |
| 1.2 - 1.8 | **Elevated** | High noise. Wider stop-losses (2.0x ATR) recommended. |
| > 1.8 | **Climax / Speculative** | Capitulation or extreme FOMO. Risk of sudden reversal is critical. |

## 📉 ATR Sizing
- **ATR (Average True Range)**: The primary measure of realized motion per bar.
- **Stop Placement**: Never place stops tighter than 1.5x ATR (24h) for intra-day trades to avoid noise-outs.
