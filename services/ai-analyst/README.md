# AI Analyst Service

## 🧠 Overview
The **AI Analyst Service** is a specialized microservice within the MTF Trading System. It acts as an institutional-grade quantitative analyst and risk manager, powered by **Google Gemini 2.5 (Pro/Flash)** and an **Agentic RAG (Retrieval-Augmented Generation)** architecture running on **LangGraph**. The service is designed for multi-timeframe market analysis, structural mapping, trade journaling insights, and automated strategy planning.

## 🏗️ Architecture & Dataflow

### Core Components
The service orchestrates AI Agents and Tools through a highly decoupled and modular architecture:
*   **FastAPI**: Provides the HTTP entry point and routes the REST/WebSocket API requests (`main.py`).
*   **LangGraph Orchestration**: Manages state transitions and node executions for agents (`StrategyAdvisor`, `MarketObserver`, `DailyBriefing`).
*   **Services**: Encapsulates core business logic, including the `GeminiClient`, `RAGService`, `MemoryService` (Qdrant), and `SentimentService`.
*   **Tools**: Specialized extraction endpoints for live data (SMC, Price, News).
*   **Persistence**: Utilizes **Redis** for short-term memory (Semantic Caching/Checkpoints) and **Qdrant** for persistent RAG vectors.

### ⚡ High-Performance Capabilities
The service is heavily tuned to minimize latency for rapid institutional operations:
*   **Layer 0 Redis Spot Fetching**: Spot prices (`features:XAUUSD:M15`) are fetched directly from the Redis stream in **< 2ms**, entirely bypassing standard HTTP timeouts and legacy polling lag.
*   **Programmatic Tool Deduplication**: Intercepts redundant tool calls generated by LLM hallucinations to protect backend services from parallel execution bloat.
*   **Semantic Caching**: Recognizes duplicated requests through Redis hashing. Identical analysis requests return instantaneously without invoking the LLM.
*   **Context & Token Pruning**: The architecture features a `Summarizer` node to aggressively condense lengthy "Scratchpad" context strings, avoiding model context saturation and 400 validation errors.
*   **Parallel Execution**: Background observation tools (like Google Search and Sentiment) are executed concurrently via `asyncio.gather`.

### 🤖 Agent Workflows

#### 1. Strategy Advisor (`StateGraph`)
The most robust conversational agent Flow designed for deep-dive analysis and strategy configuration:
1.  **Query Optimizer**: `Gemini Flash` aggressively normalizes the prompt and determines the underlying `INTENT` (e.g., `TOOL_USE` vs `RESEARCH`).
2.  **Router**: Hard-routes the request path based on the assigned Intent, bypassing unnecessary nodes.
3.  **Retrieval (RAG)**: Extracts structural User Facts, System Docs, and previous Strategy Python Code from `Qdrant`.
4.  **Reasoning**: Projects a logical "Chain of Thought" step-by-step resolution plan.
5.  **Tool Selection**: Selects optimal system tools, subject to rigorous programmable deduplication.
6.  **Execute Tools**: Executes the functions asynchronously (with "Slim" mode triggers under heavy token loads).
7.  **Generate**: Synthesizes output context into a final formatted response.
8.  **Memory Write**: Stores the extracted long-term parameters to Qdrant and the conversation sequence to Redis Checkpoint.

#### 2. Background Autonomous Observers
Unattended services running periodically on the internal scheduler:
*   **Stability Observer**: Pings the `Predictor` and `Data Pipeline` health endpoints every 15 minutes. Degraded capabilities instantly broadcast disaster recovery alerts to the `TELEGRAM_CHAT_ID`.
*   **Gold Sentiment Guardian**: Schedules continuous global macro updates. Leverages MD5 token hashing to only utilize the LLM if significant underlying RSS/News context has shifted.
*   **Session Drift Monitor**: Calculates algorithm drift and live skipped-trade rejection rates to ensure model fidelity across dynamic market sessions.

## 🛠️ System Toolset
The AI Analyst is empowered with the following operational domains:
*   **Institutional SMC**: `smc_technical_analysis` (Order Blocks, FVGs, Bias mapping), `liquidity_heatmap`.
*   **Market Sentiment & Regime**: `market_state` (Extracts Risk Multiplier from Gamma), `cot_analyst`, `open_interest`.

## 💻 Setup & Installation

### 1. Prerequisites
Installation requires the ultra-fast `uv` package manager:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Install Dependencies
```bash
cd services/ai-analyst
uv sync
```

### 3. Environment Variables
Configure the `.env` settings at the project root level:
```bash
# Core AI Logic
GOOGLE_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash

# Database & State Management
QDRANT_HOST=qdrant
QDRANT_PORT=6333
REDIS_URL=redis://redis:6379/0

# Outbound Comms
TELEGRAM_BOT_TOKEN=your_token
TELEGRAM_CHAT_ID=your_chat_id
```

## 🏃‍♂️ Running the Service

Deploy within Docker (Recommended), or independently for local Backend iteration:
```bash
uv run uvicorn app.main:app --reload --port 8000
```
*   **API Internal Docs:** [http://localhost:8000/docs](http://localhost:8000/docs)

## 💬 CLI Interface (Professional AI Term)
An advanced CLI tool is packaged for directly probing the Agentic RAG system without loading the Next.js frontend:
