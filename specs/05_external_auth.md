# External API Authentication Spec (v1.0)

This document defines the security protocol for 3rd party consumers (Partners/Bots) interacting with the MTF Olympus Gateway.

## 🔐 Security Model: HMAC-SHA256
To ensure request integrity and prevent tampering, all requests to `/api/v1/external/*` must be signed using **HMAC-SHA256**.

### Required Headers
| Header | Description | Example |
| :--- | :--- | :--- |
| `X-API-KEY` | Your unique partner identifier. | `pk_live_...` |
| `X-TIMESTAMP` | Current Unix timestamp in seconds. | `1709568000` |
| `X-SIGNATURE` | The generated HMAC-SHA256 hex string. | `a1b2c3d4...` |

---

## 🛠️ Signing Algorithm
The signature is generated by hashing a specific payload string with your **API Secret**.

### 1. Construct the Payload
Concatenate the following fields in order (no separators):
`Payload = Timestamp + Method + Path + Body`

- **Timestamp**: The same value sent in `X-TIMESTAMP`.
- **Method**: Upper-case HTTP method (e.g., `POST`, `GET`).
- **Path**: The full request path starting with `/` (e.g., `/api/v1/external/trade/execute`).
- **Body**: The raw JSON request body (string). Use an empty string `""` for GET requests.

### 2. Generate Hash
`Signature = hex(hmac_sha256(API_SECRET, Payload))`

## 💻 Code Examples

### Python (Requests)
```python
import hmac
import hashlib
import time
import requests

API_KEY = "your_key"
API_SECRET = "your_secret"
BASE_URL = "https://api.olympus.trading"

def signed_request(method, path, body=None):
    timestamp = str(int(time.time()))
    body_str = json.dumps(body) if body else ""
    
    payload = timestamp + method.upper() + path + body_str
    signature = hmac.new(
        API_SECRET.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()
    
    headers = {
        "X-API-KEY": API_KEY,
        "X-TIMESTAMP": timestamp,
        "X-SIGNATURE": signature,
        "Content-Type": "application/json"
    }
    
    url = f"{BASE_URL}{path}"
    return requests.request(method, url, headers=headers, json=body)
```

### JavaScript (Fetch/Node.js)
```javascript
const crypto = require('crypto');

async function signedRequest(method, path, body = null) {
  const timestamp = Math.floor(Date.now() / 1000).toString();
  const bodyStr = body ? JSON.stringify(body) : "";
  
  const payload = timestamp + method.toUpperCase() + path + bodyStr;
  const signature = crypto
    .createHmac('sha256', API_SECRET)
    .update(payload)
    .digest('hex');

  const response = await fetch(`${BASE_URL}${path}`, {
    method,
    headers: {
      'X-API-KEY': API_KEY,
      'X-TIMESTAMP': timestamp,
      'X-SIGNATURE': signature,
      'Content-Type': 'application/json'
    },
    body: body ? JSON.stringify(body) : null
  });
  return response.json();
}
```

### WebSocket (Real-time Stream)
WebSocket connections use HMAC authentication via **Query Parameters** since standards like `X-API-KEY` cannot be sent in standard browser-based WebSocket handshakes easily.

**Endpoint**: `/api/v1/external/ws/prices`

**Query Parameters**:
- `api_key`: Your partner key.
- `timestamp`: Current Unix timestamp.
- `signature`: HMAC-SHA256 hex string.
- `symbols`: Comma-separated list (e.g., `XAUUSD,EURUSD`).

**Handshake Signing**:
Since the handshake is a `GET` request with no body, the payload is simply:
`Payload = Timestamp + "GET" + "/api/v1/external/ws/prices"`

```python
# Example Handshake URL construction
timestamp = str(int(time.time()))
path = "/api/v1/external/ws/prices"
payload = timestamp + "GET" + path
signature = hmac.new(SECRET.encode(), payload.encode(), hashlib.sha256).hexdigest()

ws_url = f"wss://api.olympus.trading{path}?api_key={KEY}&timestamp={timestamp}&signature={signature}&symbols=XAUUSD"
```

## ⚠️ Safety Guardrails
1. **Timestamp Window**: Requests with a timestamp older than **30 seconds** will be rejected to prevent replay attacks.
2. **Secret Compromise**: If your secret is leaked, immediately rotate it via the Olympus Dashboard.
